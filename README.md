# UART Transmitter and Receiver (Verilog | Vivado)

## 📌 Overview
This project implements a UART (Universal Asynchronous Receiver Transmitter) using Verilog HDL. The design includes both transmitter and receiver modules and is verified using simulation in Xilinx Vivado.

## 🚀 Features
- UART Transmitter (TX)
- UART Receiver (RX)
- Serial communication using start and stop bits
- Simulation and waveform verification

## 🛠 Tools Used
- Xilinx Vivado
- Verilog HDL

## 📂 Project Structure
- rtl/ → Design files
- tb/ → Testbench
- sim/ → Simulation outputs

## ▶️ How to Run
1. Open Vivado
2. Add all Verilog files
3. Set uart_tb as top module
4. Run Behavioral Simulation

## 📊 Output
- TX sends serial data
- RX reconstructs data correctly

## 📚 Concepts Used
- FSM (Finite State Machine)
- Shift Registers
- Serial Communication
- Digital Design
